# 카드 가계부

카드 명세서 거래내역을 월별·분류별로 보고 관리하는 브라우저 가계부입니다.

- 진입 시 비밀번호 입력 → 암호화된 초기 데이터(`seed-data.enc.js`)를 복호화해서 불러옴
- 기기 저장 데이터(localStorage)도 같은 비밀번호로 암호화(AES-GCM, PBKDF2-SHA256 600,000회)
- 분류 자동 지정·수정·규칙, 직접 입력, 새 CSV 가져오기(중복 자동 제외, UTF-8/EUC-KR), CSV 내보내기, JSON 백업

## 초기 데이터 다시 암호화

```bash
node tools/encrypt-seed.mjs <거래내역.csv>
```

비밀번호는 화면에 표시되지 않고 저장되지 않습니다. 평문 CSV는 저장소에 올리지 마세요(`.gitignore`로 제외).
